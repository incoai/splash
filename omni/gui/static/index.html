Splash Omni

Speech, on your Mac

Read text aloud, transcribe audio, or talk with an assistant. The models run on this Mac's GPU, so nothing you say or type leaves it.

Voice
Model

Qwen3-ASR 1.7B understands 30 languages and detects which one is spoken. Files can be hours long; live captions follow the microphone.

Speech recognition, the assistant and speech run as three local servers. The assistant's model is served by Splash; about 48 GB of memory is recommended.

Voice chat needs Splash

Splash runs the assistant's language model on this Mac. Splash Omni uses the splash command of the Splash checkout it lives in; run it from one, or give the command's path under Advanced settings.

Use a running server

Any OpenAI-compatible speech server: another Splash Omni, mlx-audio, sglang-omni. Requests go to its /v1/audio/speech and /v1/audio/transcriptions; options it does not support have no effect.

            Advanced
            
            
Paragraphs separated by a blank line are sent as separate requests and played in order; the first starts playing as soon as it arrives. Once the first is generated, the others are sent at the same time as its continuations, so they keep its voice, pace and loudness.They are sent at the same time; every request carries the same system prompt and one seed, which keeps the voice close across paragraphs.

            
Paragraph mode is not offered for the Base model: it has no fixed voice, so each paragraph would sound like a different speaker. The whole text is sent as one request.

            

              
              
              
              
              
              
              
              
            

            

              
              
              
            

            
Blank fields use the server's defaults. The code predictor samples with the same temperature, top-k and top-p. Max frames: 12.5 per second of audio. Chunk frames: a fixed chunk size instead of the growing schedule. Speed: the model speaks slowly, so the page plays (and saves) its audio faster at the same pitch; 1 keeps the model's own pace.
